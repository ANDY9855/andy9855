### 🏛️ Executive Summary

Front-end developer & web development student at **Aptech (Karachi, Pakistan)** with practical production experience spanning mobile clients, enterprise backends, and commercial e-commerce operations. 

- 📱 **Mobile & Fintech Architecture:** Developing **`bizdp_mobile`**, an offline-first Flutter ledger app integrating biometric authentication and dual-key API communication against a live **Oracle 21c ORDS** backend.
- 🛍️ **E-Commerce Founder:** Built and independently operate **[Minha Fragrances](https://minhafragrances.pk)** — managing the end-to-end stack: WordPress/cPanel, MySQL database, SSL hardening, GA4/GTM/Meta Pixel conversion tracking, and payment gateways.
- 🎨 **Interface Engineering:** Focused on high-fidelity, unconventional UX ranging from an ASP.NET Core MVC platform with an "Obsidian Rose" glassmorphism theme to a fully interactive Windows XP Dark Edition web desktop.
