### ⚡ Executive Overview

<img align="right" alt="Developer Terminal GIF" width="370" src="https://github.com/AswinBarath/AswinBarath/raw/master/coding.gif?raw=true" />

I am a **Front-End Developer & Web Development Student at Aptech (Karachi, Pakistan)**, architecting production software across mobile, web, and enterprise database systems.

My engineering ethos centers on building high-stakes, resilient digital systems: from fintech-grade client ledgers with offline-first synchronization connected to **Oracle 21c ORDS**, to independently bootstrapping and scaling a live commercial fragrance venture.

* 📱 **Flagship Mobile Engine:** Designing **`bizdp_mobile`** — a Flutter enterprise ledger with biometric authentication, offline synchronization, and dual-key API auth against a live **Oracle 21c ORDS** cluster.
* 🛍️ **E-Commerce Founder:** Built and independently manage **[Minha Fragrances](https://minhafragrances.pk)** — running full-stack operations: cPanel/WordPress infrastructure, MySQL, SSL, custom tracking pipelines (GA4, GTM, Meta Pixel), and payment gateways.
* 🎨 **Obsessive Interface Design:** Creator of the **Windows XP Dark Edition** web desktop experience and the **Obsidian Rose** glassmorphism system for ASP.NET Core MVC.
* 📍 **Base of Operations:** Karachi, Pakistan 🇵🇰
* ⚡ **Philosophy:** *"I’d rather ship a broken feature and fix it live than sit on it planning forever."*
